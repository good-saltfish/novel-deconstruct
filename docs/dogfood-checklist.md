## 0. 跑之前：先把环境准备好

1. **知识库**：`ndecon reindex`（已建库可跳过；确认 290 文件可见）
2. **面板**：`ndecon panel`，浏览器开 `http://127.0.0.1:<port>`（仅回环，不要改绑地址）
3. **配模型**：顶栏 **「模型设置」** → 选供应商 → 填 key → **「测试连通」** → 保存
   - key **只存本次面板进程内存**，不落盘、不回传；重开面板要重新填
   - 8 家内置预设：DeepSeek / 智谱 GLM / 硅基流动 / Moonshot / 通义千问(兼容模式) / **本地 Ollama（免 key，离线）** / OpenAI / 自定义任意 OpenAI 兼容端点
   - 想完全离线省钱，用 Ollama 也能跑完本清单（只是暴露不出真实商用模型的行为差异）
4. **未配置时的预期报错**（出现即说明红线未破，**不是 bug**）：
   - `尚未选择模型供应商，请先在面板'模型设置'中配置`
   - `已选择 <供应商名>，但未填写 API key，请先在模型设置中保存`
   - ⚠️ 如果 AI 路径**静默降级成 Fake 出了结果**，那是红线被破，立刻记 issue。

## 1. 骨架生成（AI 路径）

面板建创作项目 → 「AI 生成骨架」，逐条核对：

- [ ] 五大部件（题材定位 / 主角 / 金手指 / 卷纲 / 10 章细纲）都能出内容
- [ ] **知识库注入生效**：生成时确实带入了方法论片段（可对比关掉知识库重跑一次）
- [ ] 输出是**聚合数字与方法论片段**，不是原文 quote（版权红线：KB 不存原文、学习检索不出原文 quote）
- [ ] 参考书**类型级拒入**：拿一本小说全本喂进去，应被拒（#17 行为不得退化）

## 2. Planner Agent（盲区重灾区，重点）

项目卡片 → **Planner Agent** 卡片 → 选任务 → 选「已配置模型」→ **运行 Agent**，然后看右侧 trace。

### 2.1 JSON 动作协议鲁棒性（roadmap 盲区第 1 条，已预先加固）

已用字符串感知的**平衡括号抽取**加固（`_iter_json_candidates`），真跑时仍请留意：

- [ ] 模型在 JSON 前后写废话（"好的，这是动作：{…} 希望有帮助"）→ 应仍能解析
- [ ] JSON 带 markdown 围栏 ```json … ``` → 应仍能解析
- [ ] **工具名乱编**（如 `rm_rf`）→ 应回"未知工具 … 可选：…"，**不中断**循环，模型能自愈
- [ ] **必填字段缺失** / 参数类型错 → 应回"参数不合法"+ hint，模型能修正后重试
- [ ] 出现 `<parse_error>` trace 步时，观察模型下一轮是否真的改对了（Reflexion 是否生效）

### 2.2 循环经济性（roadmap 盲区第 2 条）

- [ ] 12 步上限够不够用？记下典型任务实际用了几步（`turns_used`）
- [ ] `stuck_loop` 是否被真实模型触发过？触发时机合理吗（会不会误杀正常长思考）？
- [ ] observation 累积有没有撑爆上下文的迹象（报错变长 / 后半段明显失忆）
  - 注：ADR-0006 决策第 5 条「token 超预算时截断最早 observation」**第一版有意未做**，
    靠 12 步上限 + 单条 observation 截断（方法论 300 字 / 错误 200 字）兜底。真跑发现压力再补。

### 2.3 检索注入（roadmap 盲区第 3 条）

- [ ] `search_methodology` 返回的片段**相关性**如何（top-3 是否答非所问）
- [ ] `search_own_book` / `list_open_foreshadows` 命中率
- [ ] 知识库片段 + ContextPack 拼进 prompt 后的**实际长度**（有没有挤掉系统提示）

### 2.4 输出质量（roadmap 盲区第 4 条）

- [ ] 节拍是否**忠于细纲**核心事件（不是另起炉灶）
- [ ] 设定是否与**已确认金手指/主角矛盾**（矛盾时应写进 finish 汇报，而不是自行改）
- [ ] **候选不代笔**：运行后只是"候选"，点「确认」才入库（确认前不得改权威数据）

### 2.5 新增可观测字段（本轮刚落地，顺手验一下前端显示）

- [ ] trace 每步的 `latency_ms`、`total_latency_ms` 在展开「查看运行轨迹」后有没有显示
  - 注：Fake/离线路径**刻意不计耗时**（保持 trace 确定性），所以只有真实模型才看得到数字

## 3. 章节正文生成（AI 路径）
