## 〇、一句话总纲

> **把 AI 放在「编剧 / 编辑 / 资料员」的位置，永远不要放在「枪手」的位置。**
>
> 全行业唯一稳定的规则只有一条：**正文不要用 AI 生成（包括润色）。**
> 平台阈值（10% / 30% / 40%）互相矛盾且**从未有任何一家平台公布过统一阈值**——⚠️ 网传阈值表只出自一家 AI 写作工具商的商业博客。别赌阈值，赌了就是赌账号。

## 一、不可动摇的红线（事实层）

### 1.1 平台规则（✅ 官方文本/公告）

| 平台 | 允许 | 禁止 | 罚则 |
|---|---|---|---|
| 番茄 | "AI 辅助" | 打击**低质量 AI 文**（行文机械生硬、语言模板化、排版错乱无序、前后文脱节、情节逻辑错乱、故事结构崩坏）。规则文本从未写"禁止 AI"，写的是"禁止低质" | 拒签 → 减少分发 → 限制更新 → 下架整改 7/30 天 → 永久下架 |
| 起点 | 查资料、参考 | 2026-04-21 公告："反对利用 AI 或其他自动化手段替代真人完成核心内容产出"。编辑口径明确"**包括润色**" | 每月公示典型违规；2026-08-18"818 事变"：27 本均订过万作品下榜，月票榜前 1000 约 100 本清出 |
| 晋江 | **仅三项**：校对级、要素级（文章名/角色名/功夫名/人设）、粗纲级（简单人物关系 + 一两句话情节） | "用 AI 润色文字，直接由 AI 生成情节，都不被允许" | 锁章、黄牌一个月、永久禁榜；V 文须回退至 AI 前原始稿才解锁 |
| 知乎 | 唯一区分"AI 辅助创作"与"AI 滥用"并提供合法通道（创作声明）的平台 | 未声明的滥用 | 加 AI 标识 / 禁言 / 处置内容 |
| 七猫/飞卢 | 大纲、人设 | 生成正文 | — |

**治理数据（✅ 番茄官方公布）**：2026-02 处置 855 账号；05 月拒签 112,706 本 / 处置 40,275 本；07 月拒签 16 万 / 处置 5.4 万 / 账号 5,621；08 月拒签 16.3 万 / 处置 6.1 万；08-26 单次处置超 7.5 万部（下架 1 万余）、账号超 5,600（封禁 156）。

### 1.2 行业与法律（✅）

- 社科院发布会（周志雄）：阅文/晋江/番茄"**仅允许 AI 辅助梳理创作大纲，禁止 AI 代笔进行段落描写**"。
- 2025-04-30 阅文、番茄、晋江、掌阅、七猫等 16 家签署《网络文学行业反洗稿自律公约》。
- 24 家文学刊物（2026-08-24）联合声明：拒绝"AI 生成或实质性辅助创作（**包括续写、扩写、改写、润色**等核心环节）"投稿，黑名单永不采用 + 跨刊通报。**比网文平台更严：网文是"正文不能用 AI"，传统刊物是"用多少都拒绝"。**
- 司法：上海高院 2026-05-28 典型案例（组织他人 AI 洗稿 + 有偿发布服务 → 有期徒刑一年十个月至一年六个月）。⚠️ 未检索到 AI 生成**小说文字作品**著作权归属的判决。
- 标识义务：《人工智能生成合成内容标识办法》（2025-09-01 施行）第六条第四款要求平台提醒用户主动声明；番茄/纵横/七猫已上线勾选入口。**纯文本隐式标识技术上难以实现**，因此平台主要靠行为特征与文本特征判定。

### 1.3 本工具（novel-deconstruct）的工程红线

这些是**代码层面强制**的，不是建议（见 roadmap.md 第四节"不做什么"）：

1. **正文生成永不接自主 agent 循环** —— Planner Agent 8 个工具白名单里没有"写正文/删除/确认/联网"，物理上无法越权。
2. **候选不代笔** —— Agent 只产出 beats/settings 候选，必须由你在面板点"确认"才入库。
3. **知识库不存版权原文** —— 版权闸门（#27）在入库时排除全本/原文目录/章节体文本，只出方法论片段与聚合数字，**不出原文 quote**。
4. **不静默降级** —— AI 未配置时端点返回 400（"模型设置"），绝不偷偷退回 Fake。
5. **面板仅绑 127.0.0.1**，无外部 CDN。

## 二、人机分工总表

| 环节 | 谁做 | 说明 |
|---|---|---|
| ① 判断"什么值得写" | **人**（P0） | 每天扫新书榜/畅销榜 30 分钟。这是 AI 最不能替代的能力 |
| ② 选题与切入点发散 | AI 辅助 | 让 AI 给 10 个切入点/世界观钩子，你挑，**AI 不决策** |
| ③ 骨架/细纲/章纲 | AI 辅助 + 人定主线 | 你定主线与卷目标，AI 铺细纲与章纲 |
| ④ 卡普曼三角与爽点节奏排布 | AI 辅助 | 结构工具，AI 擅长；但"哪一段要爽"由你定 |
| ⑤ 第 1–3 章钩子设计 | **人手写**（P0） | 每章结尾写 3 版、读出声选一版。这是广告位，不外包 |
| ⑥ **正文** | **人手写，绝对不用 AI** | 唯一不可让渡的环节 |
| ⑦ 一致性/漏洞检查 | AI（**只让 AI 读，不让它写**） | 与前文矛盾、人设漂移、设定冲突、伏笔未收 |
| ⑧ "心理模拟器" | AI | 板面王仔用法：投一章剧情给 AI，让它模拟主角/配角心理变化，你据此自己改 |
| ⑨ 去 AI 味自检 | **人** | 见第五节。⚠️ 别用 AI 润色来"去 AI 味"——那是自证违规 |
| ⑨b 指纹密度扫描 | 本地脚本（`ndecon lint`） | 见第五节；只读，不改写 |
| ⑩ 伏笔账本 / 人物卡维护 | AI 整理，规则你定 | 见第七节的 ndecon 落地 |
| ⑪ 书名/简介/文案 A/B | AI 辅助 | 可测，风险最低的 AI 用法 |
| ⑫ 发布留痕 | **人** | Git/编辑历史/录屏，见第六节 |

**反面案例的共同结构**（✅ 起点 818 事变、番茄 2026-06 罚 49 位金番作者）：
被罚的不是"用了 AI"，而是 **「批量 + 隐瞒 + 崩坏」三件事同时出现**。写得好也在罚；被"罚死"的都是批量工作室。

## 三、每日 2 小时 SOP（⚪ 来自调研报告 8.4，可直接抄）

> 前提：日更 2000–2500 字。番茄 2026 全勤新规下，日更实际门槛已升至 5000–6600 字，按需把 B 段拉长或拆两次。

| 段 | 时长 | 做什么 | AI？ |
|---|---|---|---|
| A 章节蓝图 | 10 min | 写本章目标 / 3–5 个情节节点 / 章末钩子 | ❌ 自己定，不用 AI |
| B 手写正文 | 70 min | 2000–2500 字 | ❌ **绝对不用** |
| C 一致性检查 | 10 min | 与前文矛盾 / 人设漂移 / 设定冲突 | ✅ **只让 AI 读** |
| D 去 AI 味自检 | 15 min | 删形容词与总结句、对话单独读、读出声 | ❌ 自己做 |
| E 更新台账 | 10 min | 伏笔账本 / 人物卡 | ✅ 可用 AI 整理 |
| F 发布 | 5 min | 固定时间发 | — |

**每周额外 1.5 小时**：扫一次新书榜，记 3 个题材信号；回读 1 周前写的东西，标出"像 AI"的地方（**这是练语感的唯一办法**）。

**第 0 周一次性 6 小时**：选 1 个平台 → 扫榜 3 天锁 1 个大众题材（⚠️ 实测教训：第一本"仙侠+克苏鲁"5 万字拒签，第二本都市重生 2 万字就签）→ 建 `人物卡.md` / `伏笔账本.md` / `章节蓝图.md`（`ndecon scaffold` 生成空表，见第七节）。

## 四、Prompt 库（按环节，可直接复制）

**使用纪律（每一条 prompt 都必须带）**：
1. 明确告诉模型"不要写正文/不要润色正文"——这是双保险，防止模型自作主张输出段落。
2. 要求输出**结构化**（JSON 或固定分栏），便于你筛选而不是照抄。
3. 你只取**判断与结构**，句子永远自己写。

### P1 选题切入点发散（可用）

```
用途：拿到一个模糊题材，发散可写的切入点。
硬约束：只给切入点与钩子，不给正文、不给段落示例。

---
你是网文策划编辑。我给你一个题材方向，请给出 10 个不同的切入点。
题材：{题材}
我已有的偏好/限制：{限制}

每个切入点输出：
- 一句话卖点（不超过 30 字）
- 世界观钩子（一个具体、可感知的异常点，不要"世界观宏大"这种空话）
- 主角初始处境（弱势/被误解/背债，三选一并说明理由）
- 第一个可写单元（3 章内）的核心冲突
- 风险提示（这个切入点最容易写崩的地方）

禁止：不要写任何正文段落、不要写开头、不要写对话示例。只输出上面 5 项。
```

### P2 细纲 / 章纲铺开（可用）

```
用途：你定主线后，让 AI 铺细纲与章纲。
硬约束：只输出结构与钩子句，不输出正文。

---
你是网文大纲师。主线与卷目标由我给定，你只负责铺结构。
主线：{主线一句话}
本卷目标：{卷目标}
已确认的金手指（含限制与代价）：{金手指}
本章号：{N} / 全卷 {M} 章

请输出本章：
- 开篇钩子（一句，不超过 40 字）
- 核心事件（一句）
- 章尾钩子（一句）
- 3–5 个情节节点，每个节点标注：卡普曼三角配置（迫害者/受害者/拯救者各是谁，缺失哪个角）
- 本章应照应的未回收伏笔（我只给你清单，你判断哪些该在本章照应）

禁止：不要写正文、不要写段落、不要润色任何句子。只输出结构与判断。
```

### P3 人物语音卡（可用）

```
用途：给主要角色建"语音卡"，提升对话区分度。
硬约束：只输出特征清单，不写示例对话。

---
角色：{角色名} / 身份：{身份} / 与本作主角关系：{关系}

请输出该角色的语音卡：
- 口头禅（0–2 个，不要网络流行语）
- 句子长度倾向（短句为主 / 长句为主）
- 是否打断别人、是否反问、是否回避正面回答
- 在"被冒犯 / 被求助 / 被威胁"三种情境下各自的第一反应动作（动作，不是台词）
- 这个角色的盲区（他永远意识不到的自己的问题）

禁止：不要写示例对话、不要写台词。只输出特征清单。
```

### P4 卡普曼三角排布检查（可用，方法论来自 `教程.md`）

```
用途：检查一章的冲突密度与三角轮转是否合格。
硬约束：只做结构诊断，不改写文本。

---
下面是我这一章的情节节点列表（只列节点，不含正文）：
{节点列表}

请按卡普曼三角（迫害者 / 受害者 / 拯救者）逐个节点标注：
- 三角是否完整（完整=紧张期待释放；缺迫害或缺拯救=焦虑憋屈；未爆发可预感=不安）
- 三角是否发生了"流转"（角色换位），还是同一配置重复
- 诊断：本章三角数量、600 字内是否有变化、"承"段是不是同一迫害行为换姿势加量

参考判据：一章 3 个三角=情绪趋势 v，5 个=w，7 个=ww；一章 5 个三角≈15 次交互≈2500 字。
编辑判据：一章 5–10 个冲突结构；快一千字了还没有一个冲突结构就是问题。

禁止：不要改写我的节点、不要补写正文、不要润色。只输出标注与诊断。
```

### P5 一致性 / 漏洞审查（可用，**只让 AI 读**）

```
用途：C 段（每日 10 分钟）用。把已写内容喂进去找矛盾。
硬约束：只报告问题，不给出改写后的文本。

---
你是 continuity editor。下面是我已发布的章节要点与设定。请找出：
1. 与前文矛盾（时间线、地点、人物已知信息、能力边界）
2. 人设漂移（某个角色的反应与其已建立的立场不符）
3. 设定冲突（与金手指的限制/代价矛盾）
4. 未回收的伏笔（列出开了没收的）

已确认设定：
{设定}

已写章节要点：
{章节要点}

输出格式：每条按 [类型] 位置 / 问题 / 为什么是问题 三栏列出。
禁止：不要给出修改后的文本，不要润色，不要替我写句子。只报告。
```

### P6 心理模拟器（可用，⚪ 来自番茄新锐作家"板面王仔"实测）

```
用途：写完后让 AI 模拟角色心理，你自己据此改。
硬约束：只输出心理推演，不输出可粘贴的正文。

---
下面是这一章的剧情（我只给你情节，不给正文）：
{情节}

请分别模拟 {主角}、{配角A}、{配角B} 在此刻的心理变化链：
看到什么 → 身体先卡在哪一下 → 想做什么但被什么挡住 → 最后做了什么

然后指出：我当前的情节安排里，哪一处的角色反应不符合上面推演出的心理链。

注意（⚪ 实测提醒）：这个用法会让修改时间翻倍（写一章 1 小时，改 2–3 小时），
且容易让人"看了 AI 的答案后变得极不自信、反复修改"。请你只把它当纠错器，不当裁判。

禁止：不要写正文、不要写对话、不要给可直接粘贴的段落。
```

### P7 书名 / 简介 A/B（可用）

```
用途：低成本可测的 AI 用法。
硬约束：只给候选与理由，不写正文。

---
题材：{题材} / 一句话卖点：{卖点} / 目标平台：{平台}

给出 8 个书名候选，每个标注：信息量（读者一眼能看出什么）、情绪指向、风险（是否撞名/是否空泛）。
再给 3 版简介（每版不超过 120 字），分别走：悬念前置 / 利益前置 / 反差前置 三种路子。

禁止：不要写正文开头、不要写第一章。
```

### P8 扫榜信号提炼（可用）

```
用途：把扫榜数据变成可执行的题材信号。
硬约束：只提炼信号，不复述榜单内容、不抄任何作品情节。

---
下面是近期榜单的题材/标签分布（只给数字与标签）：
{分布}

请回答：
1. 哪 3 个题材信号在上升？依据是什么（给数字）
2. 哪些是"看起来热但已拥挤"（给出拥挤度判断依据）
3. 对我当前的题材 {题材}，结论是：跟 / 不跟 / 跟但换角度。给理由。

禁止：不要复述任何作品的具体情节与表达，不要照抄。
```

### ❌ 禁止类的 prompt（无论多诱人都不要写）

| 不要写 | 原因 |
|---|---|
| "帮我写第 N 章" / "续写下面这段" | ✅ 全平台禁止，起点编辑明确"包括润色" |
| "帮我把这段润色一下" | ✅ 晋江明文禁止，起点编辑口径禁止，24 家刊物连"润色"都拒 |
| "把这段改得不像 AI" | 用 AI 去 AI 味 = 自证违规；且⚪ 实测"为压检测率改出的句子人读着更别扭" |
| "批量生成 20 章" | ✅ 五大方向已同时堵死（上游拒签/中游撤榜/下游砍价/司法/同业） |
| "写个脚本绕过检测" | 性质从**违规变欺诈**；风控最擅长抓"文本说没用 AI + 行为全是 AI" |

## 五、去 AI 味自检清单

### 5.1 认知层（最重要的一句）

> **"AI 味的本质是这段话谁都能写。你把里面的人名换掉、行业换掉，它照样成立。"**

**自检土办法**：写完后把所有专有名词换掉，如果照样成立 → 有 AI 味。

**⚠️ 必须记住**：**"读起来不像 AI" ≠ "检测不出来"**，这两件事经常打架。

### 5.2 五种核心改写法（⚪ 来自 Chinese-WebNovel-Skill）

| 症状 | 改法 |
|---|---|
| 总结句（"她很慌"） | → 动作句：谁先碰了什么、谁该说话却没说 |
| 情绪句 | → 反应链：看到什么 → 身体先卡哪一下 → 做了什么掩饰 |
| 气氛句 | → 场内变化：谁突然安静、哪个声音突然被听见 |
| 标签句 | → 判定动作：让他做一个足以让别人收声/退步/改口的动作 |
| 说明书对白 | → 压迫对白：说立场、条件、后果、最后通牒 |

### 5.3 可量化的"AI 指纹"阈值（⚪ 来自 novel-writing-framework，500+ 章实战，四级信源，需自验）

> **本项目的 7 条阈值已工程化为 `ndecon lint`**（`src/ndecon/quality/fingerprint.py`，规则集 `fp-v1`）。
> 纯本地、离线、确定性，**只报告实测值与阈值对比，绝不产出改写后的文本**——改什么由你决定。
>
> ```powershell
> python -m ndecon.cli lint 第12章.md            # 只读报告
> python -m ndecon.cli lint 第12章.md --strict   # 有越界时非零退出（可挂 git hook / CI）
> ```
>
> 面板里点章节卡片的「指纹体检」按钮走的是同一个扫描器（`GET /api/projects/{id}/chapters/{order}/lint`），
> 报告里每条规则给出**实测值 / 阈值 / 命中样本**，越界项标红——同样只报告，不给改写文本。
>
> 阈值常量在 `fingerprint.py` 顶部，可按自己的语感校准；扫描逻辑不变。
> ⚠️ 阈值按**单章约 5000 字**校准，扫整篇长文档时 CLI 会提示"绝对次数不可直接对比"。

| 指标 | 阈值 |
|---|---|
| "不是 X 是 Y" 句式 | ≤ 2 次/章（该项目实测 663 次 → 清洗到 31 次，是全书工作量最大的单项修复） |
| 中文破折号 `——` | ≤ 1 处/章（更严：全书 ≤ 20） |
| 段落内句号 | ≤ 2 个 |
| 一段内比喻 / 整章比喻 | ≤ 1 / ≤ 3 |
| 连续"的" | ≤ 2 个 |
| 场景轮换 | ≥ 5 个（曾连续 17 章同一场景） |
| 每章 CJK 字数 | ≥ 2000 |

**其他已知特征（✅/⚪）**：完全 AI 代写——"一点活人味儿都没有"、剧情起伏小、**标点过于规范，频繁使用破折号、顿号甚至单引号**（"很多网文作者几乎不会用到单引号"）；AI 润色——反复使用固定描述方式、**加入与剧情无关的比喻和描写**；真人写的——更口语化、**过渡更短**。

**⚠️ 反例**：爱伦坡《黑猫》被判"包是 AI 写的"——**"AI 味"的主观判断不可靠**。

### 5.4 检测准确率反证（✅ 有来源）

老舍《林海》被判 99.9% AI；朱自清《荷塘月色》62.88%；刘慈欣《流浪地球》52.88%；作者 2017 年旧作被判 90%（结果要么 0% 要么 90%，无中间值）；Stanford 称 Turnitin 误判 67%。

**结构性洞察**：**检测惩罚的不是"像 AI"，是"太规范"。** 所以刻意写得"不规范"是错方向——应该写得**有你的语感**。

### 5.5 行为层风控（对新手最关键，✅）

番茄：每天最多建 1 部 / 每月 3 部；单作品每日更新字数上限按作者等级浮动；**提现需人脸识别**。
→ **"新手只要保持一个人、一个号、正常更新量，就避开 90% 风控。"**

### 5.6 语感退化警告（⚪ 编辑观察，但值得当真）

编辑花满观察：长期用 AI 润稿的作者会"逐渐照着 AI 的表述来修改语言……现在他已经写不出自己原来的语感了"——**语感退化不可逆**。
→ 对应 SOP：**每天写 500 字"绝对不喂 AI"的原稿**，每周回读一个月前的。

## 六、自证留痕（从第一天开始做，且要"给别人看的"）

被误判时的举证责任在平台方（✅ 全国首例，北京互联网法院 2025：平台"既是算法工具掌控方又是结果判断方"，应就判定结果合理举证，判**构成服务合同违约**）。但你得先有东西可举。

| 手段 | 说明 |
|---|---|
| **Git 提交历史** | ⚪ 最推荐：`git log` 是天然创作过程证据链。**用本地编辑器（VS Code/Typora/Obsidian）+ Git 写正文**，别在平台"AI 助手"面板粘贴正文 |
| 文档编辑历史 | WPS/Word/云文档的版本记录 |
| 大纲手稿 / 灵感笔记 | 手写或本地文件，带时间戳 |
| 一镜到底录屏 | ✅ 起点作者"鬼谷道长"架手机录屏 + 语音输入口述 40 分钟写 4000 字自证 |

**⚠️ 反直觉但重要**（晋江站长冰心）："越是用过 AI 的，越是有条件找到证据；反而是**从来没碰过 AI 的，一点自证的空间都没有**"——纯手写作者在制度上是裸奔的。

**给技术型写作者的三条**：① 编程能力在网文行业是劣势，唯一正向用法 = 做档案管理、一致性检查、自己的质量 linter（**把 AI 当工程工具，而不是当写手**）；② 不要写规避检测脚本；③ 从第一天开始留痕。

## 十、铁律（背下来）

> **"能靠 AI 文赚钱的人，手搓也赚钱。"**
> AI 是放大器，不是印钞机。

期望管理（番茄 ✅ 数据）：上架近 70 万作者，年入 3 万以上 9,374 人 ≈ **1.3%**，年入 10 万以上 3,228 人 ≈ **0.46%**；2025 新增注册作者 285 万、新增签约 22 万 ≈ **7.7%**。

5 年预判：产能层被 AI 吃掉；"作者"层重新定义并**涨价**；变现从"卖字数"转向"卖 IP"。升值的能力 = 人味识别度、长线结构能力（百万字人设不崩、伏笔能收）、IP 可改编性设计、AI 工作流整合能力。
